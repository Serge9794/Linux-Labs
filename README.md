## 🎯 À propos de ce dépôt

Ce dépôt regroupe des **projets pratiques Linux réalisés sur des systèmes réels (RHEL 9 / Ubuntu)** dans le cadre de la préparation à la certification **RHCSA (Red Hat Certified System Administrator)**.

Chaque projet documente un scénario d'administration système concret : sécurité SSH, gestion des utilisateurs, automatisation Ansible, stockage LVM — avec les commandes exécutées, les fichiers de configuration et les résultats de tests prouvant le bon fonctionnement.

## 🛠️ Environnement de travail

- **RHEL 9 / CentOS Stream** — systèmes de test principaux
- **Ubuntu 22.04** — environnements complémentaires
- **Ansible** — automatisation des configurations
- **VirtualBox / Azure VMs** — infrastructure de lab

---

## 🎓 Objectif de certification

Ces labs préparent à l'examen **RHCSA (EX200)** de Red Hat, couvrant les domaines :
- Gestion des fichiers et permissions
- Sécurité SSH et SELinux
- Administration des services systemd
- Gestion du stockage (LVM, partitions, systèmes de fichiers)
- Automatisation avec Ansible
